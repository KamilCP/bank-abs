# Bank ABS — автоматизована система діяльності банку

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення»
(Фаховий коледж «КАІ ТЕХ» НАУ, група 581-ІПЗ, Сабіржанов К. Р.).

Веб-застосунок для працівників банку: облік клієнтів і рахунків, касові операції і перекази з
конвертацією валют, депозити з капіталізацією, ануїтетні кредити з графіком погашення, звіти для друку,
статистика, адміністрування користувачів і прав доступу, журнал подій.

**Поточна версія:** 0.2.0-beta.1 · Задачі: Jira, проєкт `BANK` · Методологія: Scrum (спринти по 3 тижні)

## Технології

* C# 14 / .NET 10, ASP.NET Core Blazor (статичний серверний рендеринг з покращеною навігацією), Bootstrap 5, Bootstrap Icons
* PostgreSQL 18 (сумісно з 16+), Npgsql; бізнес-логіка операцій — функції і процедури PL/pgSQL, аудит — тригери
* xUnit (89 тестів: модульні та інтеграційні), GitHub Actions (CI)

## Швидкий старт

1. Встановіть .NET SDK 10 і PostgreSQL 18.
2. Створіть порожню базу:
   ```bash
   createdb -U postgres bank_abs_dev
   ```
3. Задайте рядок підключення (пароль не зберігається в репозиторії):
   ```bash
   cd src/BankAbs.Web
   dotnet user-secrets set "ConnectionStrings:BankAbs" "Host=localhost;Port=5432;Database=bank_abs_dev;Username=postgres;Password=<ваш пароль>"
   ```
4. Запустіть програму — під час першого запуску вона сама створить таблиці, функції, тригери і демонстраційні дані:
   ```bash
   dotnet run --project src/BankAbs.Web
   ```
   або відкрийте `BankAbs.slnx` у Visual Studio 2026 і натисніть F5.

## Структура

```
src/BankAbs.Domain   — сутності, бізнес-правила, розрахунки (IBAN, РНОКПП/ЄДРПОУ, ануїтет, депозити, паролі)
src/BankAbs.Data     — репозиторії ADO.NET, ініціалізація БД вбудованими скриптами
src/BankAbs.Web      — сторінки Blazor, автентифікація і права, звіти, статистика
tests/BankAbs.Tests  — модульні та інтеграційні тести (xUnit)
db/                  — 01_schema, 02_functions (функції і процедури), 03_triggers, 04_seed
docs/                — стандарти кодування та інтерфейсу, збирання і нумерація версій
```

## Тести

```bash
dotnet test BankAbs.slnx
```

Інтеграційні тести серверної частини БД запускаються, якщо задано змінну середовища
`BANKABS_TEST_CONNECTION` з рядком підключення до бази, створеної скриптами `db/*.sql`;
кожен тест виконується в транзакції з відкатом.
